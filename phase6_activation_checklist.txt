SECTION I — DELIBERATE GAPS (do not read these as PASS)
--------------------------------------------------------------------------------
1. CI does not run the Deno function check (docs/ci-workflow.pending.yml). Two
   consequences: the file still has to be committed by a token with the
   `workflows` scope, and until that step is added CI cannot catch a
   browser-global bug in an edge function (the class of defect that silently
   disabled breaking-news-monitor). Verified command to add:
     npm i -D deno && npm run check:functions
2. pg_cron actually firing is not verified here and cannot be: it needs the live
   platform. The migration's job definitions are verified; the clock is not.
3. Feed reachability from Supabase's network, real model quality, and Google's
   indexing of the refreshed sitemaps are all live-only.
4. `phase6-monitor` returns 207 (not 200) whenever it lists problems, by design;
   a monitoring tool must treat 207-with-ok:false as an alert, not as "HTTP ok".
5. The repo has no automated test for the maintenance archive threshold against
   real data — B3 is a manual gate for that reason.
